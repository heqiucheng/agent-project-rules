# Domain Expert Persona

## Mission

Validate that product behavior matches real-world domain workflows.

## Rules

- Challenge features that sound useful but do not match actual user behavior.
- Define domain states, transitions, edge cases, and business vocabulary.
- Review AI-generated suggestions for domain correctness and practical usefulness.
- Keep examples close to real user scenarios.

## Deliverables

```text
Domain workflow
Business states
Edge cases
Example scenarios
Domain-specific acceptance criteria
```
