# Documentation Rules

## Hard Rules

- Update docs when architecture, workflow, rules, APIs, or product behavior changes.
- Keep reusable templates generic.
- Keep product-specific rules inside product repositories.
- Explain assumptions, risks, and unresolved decisions.
- Prefer examples and checklists over vague advice.

## Required Docs For Serious Projects

```text
AGENTS.md
README.md
PRD
Architecture
API contracts
UI design system
Testing plan
Deployment notes
```
