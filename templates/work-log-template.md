# Work Log Template

Use this template for multi-step, resumed, long-running, or verification-heavy tasks.

## Header

```text
Task:
Owner:
Started:
Current status:
```

## Startup Audit

```text
Instruction chain:
Runtime capability state:
Governance files in scope:
Initial scope lock:
Initial diff budget:
```

## Goal And Assumptions

```text
Goal:
Why this matters:
Assumptions:
Non-goals:
```

## Validation Plan

```text
Required checks:
Evidence to collect:
Blocking dependencies:
```

## Checkpoints

```text
[time] Decision:
[time] Changed:
[time] Validation:
[time] Evidence:
[time] Risk:
```

## Handoff

```text
Current status:
What is verified:
What is not verified:
Open risks:
Next action:
```
